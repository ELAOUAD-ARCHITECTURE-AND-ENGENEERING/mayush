## Guidelines

- Use descriptive filenames with date prefix: `YYYY-MM-DD_backup-description.ext`
- Include the version or commit hash in the filename when applicable
- Backups of sensitive data (e.g., `.env`) should be added to `.gitignore`
- Periodically clean up outdated backups to save storage
