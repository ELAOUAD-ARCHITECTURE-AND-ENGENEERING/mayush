feat: comprehensive stabilization, seller onboarding, and core enhancements

This commit aggregates several major feature implementations, bug fixes, and system stabilizations across the Mayush marketplace.

### 1. Seller Onboarding Workflow
- Implemented a secure, multi-stage seller onboarding and approval workflow.
- Established a "pending approval" status upon registration, blocking dashboard access until admin authorization.
- Developed a mandatory document upload interface for contracts, photo IDs, and business documents with file validation.
- Created an admin interface to manage, approve, or reject applications with mandatory feedback fields.
- Implemented automated email notifications for all stages of the workflow.

### 2. Payment & Checkout Fixes
- Fixed CMI Payment Method Not Allowed Error (`MethodNotAllowedHttpException` on `/cmi/success` route).
- Updated route definitions and `VerifyCsrfToken` middleware exclusions for payment callbacks.

### 3. Routing & Middleware Stabilization
- Resolved recurring 404 Page Not Found errors on the local root URL.
- Fixed `TrustProxies` middleware incompatibility with the local environment.
- Restored marketplace routing integrity, fixing widespread `RouteNotFoundException` errors in seller and admin dashboards.
- Added missing named routes and corrected broken controller method mappings.

### 4. Translation & Globalization
- Globalized model translation fallback logic in over 20 core models via `getTranslation()`.
- Ensured automatic fallback to the static `translations` table when model-specific records are missing.

### 5. Database, Models & Blog System
- Fixed `QueryException` by adding missing columns (`hot_category`, `meta_keywords`) to `categories`, `products`, and `brands` tables via forward migrations.
- Expanded the Mayush Blog system with database migrations for authorship, tags, and multi-language content (`blog_translations`).
- Added robust relationships to the `Blog` model and seeded localized content.

### 6. Testing & Quality Assurance
- Stabilized the integration test suite, ensuring a consistent pass rate.
- Isolated non-payment tests and replaced hardcoded URLs with named routes.
- Implemented reusable test configuration traits and added testing for CSRF protection, middleware, and controller logic.
