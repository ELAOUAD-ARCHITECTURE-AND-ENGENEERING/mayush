# Mayush Buyer Flow Map

Status: route and prototype plan prepared; Figma prototype links remain pending MCP capacity.

- Entry: Splash → Language selection → Onboarding → Home
- Discovery: Home → Categories → Product listing → Filters / Search → Search results
- Product: Product details → Gallery / Variants → Wishlist or Cart
- Authentication: Auth welcome → Login or registration → OTP → Account created → Intended action
- Cart & wishlist: Wishlist → Variant selector → Cart → Coupon → Checkout
- Checkout: Address → Delivery → Payment → Review → Processing → Confirmation
- Orders: Orders → Detail → Tracking → Cancellation / Return / Refund → Support
- Account: Account → Personal details / Addresses / Security / Notifications / Preferences
- Support: Help center → Article → Contact support → Ticket conversation → Resolution
- System: Offline → Reconnect → Restored; Update available → Required update → Completion

RTL rule: use a locale variant, mirror navigation and horizontal layouts, right-align Arabic copy, and retain unmirrored product photography unless the content requires it.
