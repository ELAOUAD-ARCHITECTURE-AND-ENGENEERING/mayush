| Actions | Button, Icon Button, FAB | Style, size, enabled, loading, icon position |
| Forms | Text Input, OTP Input, Search Field, Checkbox, Radio, Switch, Quantity Stepper | State, value, supporting text, locale |
| Commerce | Product Card, Product Item, Cart Item, Price Block, Rating Block, Variant Chips | Layout, state, locale, image/badge/price visibility |
| Checkout | Address Card, Delivery Card, Payment Card, Order Summary Row | Selected, disabled, locale |
| Orders | Order Card, Status Badge, Tracking Step, Package Card | Status, compact/full, locale |
| Account & support | Settings Row, Profile Header, Ticket Card, Conversation Message, FAQ Accordion | Direction, state, icon visibility |
| Feedback | Toast, Confirmation Dialog, Bottom Sheet, Empty State, Error State, Skeleton, Offline State | Intent, action visibility, locale |
